# BC-LAC-02 — 机制归属：会不会把同义替换判成隐喻、把连贯切换判成转喻

**Tests:** [`SOP-LAC-02`](../../SOP/Lacan-Studies-Preliminary/SOP-LAC-02-metaphor-metonymy-attribution.md) 的护栏（替代≠隐喻、
组合≠转喻）与 3.2 的效果证据门槛是否真的可执行 · **Data:** 自制的中性短文本，非两书原文 · **Source package:** 沈志中
《永夜微光》、张一兵《不可能的存在之真》

## 1. 待测能力／失败

被检查的失败有两型：**过度归属**（把一次替换动作或一条话题线直接叫作隐喻／转喻）与**对译滑移**（沿用中文对译词而不检
查它对应哪个外文词，把 Entstellung 与 Verschiebung 混为一谈）。第二型之所以要测，是因为两本书本身的中文词就不齐（沈写
"凝缩／移置"改写成"转喻／隐喻"，张把"移置"标为 Entstellung），下游照抄就会把错位固定下来。测试对象是文本分析质量：能
否指出可指认的痕迹、能否在痕迹不足时停在"未定"。不测病因，不测无意识内容的真伪。

## 2. 案例与比较

材料均为自制短文本，不冒充书中引语。检验重点是语言操作与**机制解释**能否分开，而不是强迫解释者从两个类别中选一个。

| arm | 材料 | 应辨别的事实与解释 |
|---|---|---|
| a | 作者谈新上司时反复误称“老爸”，后文又使用“继承”与“任命”构成新说法 | 存在词语替代、回返和意义变化，**可提出隐喻候选解释**；不意味着已证明实际主体的无意识机制 |
| b | 一份说明把“客户”统一改成“用户”，全文无其他变化 | 可确认编辑替换，不可直接确认隐喻意义效果 |
| c | 访谈者从某个话题转向办公室、通勤、排班，并反复说“有关系”却不解释 | 可确认相邻话题链与回避性叙述；**回避或“答不出”不是转喻的充分条件**，还应保留普通回避、叙事组织等竞争解释 |
| d | 会议发言顺次承接邻近议题，内容均可复述 | 可确认邻近组合，不足以推出无意识转喻机制；**能否复述内容也不是排除语言学转喻的通用标准** |
| e | 评论仅写“这是移置的作用”，没有外文词与文本根据 | 不得将 Entstellung、Verschiebung、déplacement 在不同译本间机械等同 |

## 3. 判读与失败

检查是否定位具体词语关系、注明来自哪条文本证据、给出至少一种非拉康式的替代解释，并区分“机制候选”与“已经证实”。若仅凭词汇替换就断言隐喻，或把话题回避当作转喻的**充分证明**，记作越界。若以历史曾设立的“隐喻至少一项痕迹、转喻必须两项”门槛判对错，属于**无来源支持的判据**，不能继续使用。

比较未执行 SOP 与执行后的解释是否少了上述跳步。没有数值评分，也不以必须输出某个标签作为通过条件。

## 4. 既往试用（旧版结论暂停）

原稿记录五例均已试用，曾因旧判据把 arm d 判为转喻，随后补入“不对称门槛”；a、c 也曾依该门槛标为“通过”。本次审阅发现门槛本身无充分来源，故**旧版通过状态不再有效**。原始试用记录作为历史事实可从 Git 提交查阅；下一轮只需重跑 a–e 并记录关键解释与被拦住的跳步，不新设规则表。

## 7. 有效性边界与可溯性

本 BC 只检验按 SOP 执行时机制归属是否稳定，不证明隐喻／转喻在拉康理论中的地位，也不证明任何文本背后的心理事实。判据
全部来自两本书的中文重构，其注号与讲座页码在本阶段不可回核
（[`SOURCE.md`](../../Validation/Lacan-Studies-Phase1/SOURCE.md)）；沈记述的"误用隐喻公式导致错误理论结果"是本 BC 设定
门槛的动机，但它是被记述的批评，不是本 BC 检验的对象。

**Historical boundary.** 隐喻／转喻的操作定义、缝合点与后遗时间这些装置，在这里的身份是两位研究者各自的重构。本 BC 不
重建任何公式（本地电子件中相关公式多已丢失，见【永】§十五清单），也不把机制归属转述为拉康的定版学说或临床规则。
