# Lacan studies — preliminary Benchmark package（草案）

**Status: draft.** 与 [`SOP/Lacan-Studies-Preliminary/`](../../SOP/Lacan-Studies-Preliminary/README.md) 一对一配对的检验。
本阶段材料基础见 [`Validation/Lacan-Studies-Phase1/`](../../Validation/Lacan-Studies-Phase1/SOURCE.md)。

每个 BC 检验一件**具体的文本分析失败**，而不给任何概念"打分"。材料分两类：自制的中性短文本（BC-LAC-01、02）与两书实际
记述过的论断的转述加自制下游句（BC-LAC-03）；没有一条使用编造的原书引文或页码。判读不设数值阈值，因为两个来源都没有提
供容差——改为检查论证是否直接由材料支持、是否给出可辩护的竞争解释、是否停止不当推断，不再用固定字段数量当作失败门槛。

| BC | 检验什么失败 | 正例／易混对照 | 由哪个 SOP 执行 |
|---|---|---|---|
| [`BC-LAC-01`](BC-LAC-01-desire-triad-assignment.md) | 层次升降；把结构假设写成发生史 | a 认可关系候选／b 对象更替但未定，兼测 c 生理线索、d 他人期待、e 发生史证据 | `SOP-LAC-01` |
| [`BC-LAC-02`](BC-LAC-02-metaphor-metonymy-attribution.md) | 替代当隐喻、组合当转喻；对译词滑移 | a 隐喻候选／c 关联链与回避但未定，对照 b 编辑替换、d 话题衔接、e 术语错位 | `SOP-LAC-02` |
| [`BC-LAC-03`](BC-LAC-03-claim-strength-under-evidence-gaps.md) | 作者重构被写成拉康主张；缺件被当作论证失效；交叉注条被草率裁决 | a 位置关系可复原／e 同节两半分档，对照 b 编排顺序误判、c 自铸标签、d 局部撤回、f 译名混用 | `SOP-LAC-03` |

**试用状态**：上一轮完成 15 项案例（BC-01 的 c 未执行），但本轮发现部分判据与答案不成立并已修正。旧执行记录不抹去；涉及这些旧判据的 PASS 已撤销，**目前状态为已完成修补、等待有限重测**。见各 BC 的历史记录说明与 [`REVISION-01.md`](../../plans/Lacan-Studies-Preliminary/REVISION-01.md)。

**这些检验不能确立什么**：不证明需要／要求／欲望或隐喻／转喻的区分在拉康文本中就是这样，也不证明任何一条区分在经验上
成立；不评价两书谁更忠实；不测临床疗效，不测任何解释的真理值。它们只回答一个问题：按这份 SOP 执行时，判断是否稳定、
是否在证据不足处停住。

**Historical boundary.** 判据全部来自沈志中（2019 台大出版中心纸本对应的社区重排 PDF）与张一兵（上海人民出版社 2020 修订
本 EPUB）这两本二手研究；前者无印刷页码且公式图版大量丢失，后者尾注自 [72] 起在电子件中缺失，两书均未回核原典。取得纸
本或原典后，本包的期望输出需要重跑，而"不得补写缺失装置""不得把作者重构写成拉康主张"两条限制不因此放松。
