# 拉康研究：初步 BC（文本分析测试）

这里的 BC 评价**分析是否按现有文本作出了可追溯的解释**，不评价分析对象的人格、临床效果或拉康理论“真伪”。测试所用参照来自[第一阶段笔记](../../Validation/Lacan-Studies-Phase1/)；该阶段是二手文献研究，未完成原典核验。

- [BC-LAC-P01：归因与引证越界](BC-LAC-P01-attribution-fidelity.md)，对应 [SOP-LAC-P01](../../SOP/Lacan-Studies-Preliminary/SOP-LAC-P01-textual-attribution.md)。
- [BC-LAC-P02：概念区分与强推论](BC-LAC-P02-concept-boundaries.md)，对应 [SOP-LAC-P02](../../SOP/Lacan-Studies-Preliminary/SOP-LAC-P02-concept-comparison.md)。

两组均采用**具体陷阱案例 + 必须保留的区分 + 失败条件**，不用加权分数、伪精度阈值或独立测试框架。运行时记录每项案例是否满足全部关键条件及失败原句；只有实际跑过案例才能报告通过，不得仅凭文件存在标记 PASS。证据仍受电子版本与注释缺失限制。
