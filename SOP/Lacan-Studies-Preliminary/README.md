# 拉康研究：初步 SOP（仅二手文献阶段）

此组 SOP 根据 [第一阶段两书的概念重构](../../Validation/Lacan-Studies-Phase1/concept_reconstruction.md) 提炼，属于**试行方法**，不是拉康原典研究的定论，更不是临床精神分析操作规程。

- [SOP-LAC-P01：文本主张与归因重构](SOP-LAC-P01-textual-attribution.md) —— 一句话究竟是谁说的、根据什么说、是否查得到。
- [SOP-LAC-P02：跨书概念辨析](SOP-LAC-P02-concept-comparison.md) —— 两本书使用同一术语时，究竟是共识、不同问题还是实质冲突。

顺序：先 P01 保证每条关键材料有归因和定位，再用 P02 进行比较。只在有实际分析任务时使用，不批量套模板。对应检验见 [BC 组](../../Benchmark/Lacan-Studies-Preliminary/README.md)。

**材料边界**：沈志中《永夜微光》所用社区重排 PDF 缺失多项公式、图示；张一兵《不可能的存在之真》所用 EPUB 的注释自 [72] 起缺失。[来源记录](../../Validation/Lacan-Studies-Phase1/SOURCE.md)与[阅读覆盖说明](../../Validation/Lacan-Studies-Phase1/reading_map.md)注明这些限制。两部二手研究均未经拉康原典逐条验证。
