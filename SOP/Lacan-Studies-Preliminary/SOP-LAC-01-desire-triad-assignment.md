# SOP-LAC-01 — 判定一段叙述里的"追求"落在需求、要求还是欲望上

**Stage:** 文本与理论分析中的层次归属 · **Source package:** 沈志中《永夜微光》、张一兵《不可能的存在之真》（两本二手研究）—
版本与定位限制见 [`SOURCE.md`](../../Validation/Lacan-Studies-Phase1/SOURCE.md)，概念对照见
[`concept_reconstruction.md`](../../Validation/Lacan-Studies-Phase1/concept_reconstruction.md) §四。
**配套检验：** [`BC-LAC-01`](../../Benchmark/Lacan-Studies-Preliminary/BC-LAC-01-desire-triad-assignment.md)

## 1. 目的与范围

研究的实际问题：一段文本说"他要 X"，而 X 到手之后事情并没有结束。三位一体的区分之所以必要，是因为"没有结束"
有三种性质完全不同的原因，混用它们会让随后的每一步论证失效。把不可满足写成"还没得到够好的 X"，是把欲望降格为
尚可满足的要求；把开口就要的东西直接称作欲望，是把可由给予关系终止的要求升格为欲望；而把三层说成同一件事的深浅两
档，则取消了区分本身。本 SOP 提供三个可执行的测试，使层次归属成为可检查的判断，而不是措辞的选择。

范围只到**文本内的层次归属及其许可的推论**。它不是临床操作程序，不构成对任何真实个体动机的判断，也不宣称这套三
分在经验上被验证过——它是两位研究者各自重构的诠释装置。

Out of scope：一个能指构成物属于隐喻还是转喻（`SOP-LAC-02`）；二手论断在当前证据下能写多强（`SOP-LAC-03`）。

## 2. 输入与前提

- 待分析文本，以及其中"被追求的东西"至少一个可指认的位置。文本若没有交代"给出对应物之后会怎样"，把该项记为未
  知，不要代作者补齐。
- 一句声明：本判定采用哪一套区分。沈志中把三分建立在**落差**上（需求是生物事实、对应可满足客体；要求是需求经语言
  向他者提出时的必然异化；欲望诞生于需求与要求之间的落差，【永】§二 p.59）；张一兵建立在**失去**上（本真的需要、异化
  的要求，"从要求减去需求即得欲望"，【张】§七 EPUB 文件54·P003）。两套给出的判准不同，不能合成一个普遍定义后再使用。
- 前提：两书中的"拉康认为"均未回核拉康原典（SOURCE.md 第 3 节）。凡本 SOP 用到的概念规定，都要以"某书如此重构"
  的身份进入结论。

## 3. 步骤

### 3.1 终止测试：找出对应物

列出文本中的追求对象，逐一问一句：给它之后，叙述里的不安是否终止。可由对象终止、且终止后不再以同一形式复发的是
需求候选。沈对需求的定义正是"生物事实、对应可满足客体"（【永】§二 p.59），因此该测试不是心理判断，而是文本结构判断：
不安随对象到场而结束，还是不随对象到场而结束。

### 3.2 给予者测试：区分要求与需求

若对应物已经给出而仍不满意，先检查不满落在哪里。落在"是否由他主动给、是否在我开口之前、以什么姿态给"上，就是要求：
要求真正指向的是他者的意愿与在场。张把这一层说得最直白——要求的目的是母亲的爱，其对象是"一个不在场的在场"，而语言
介入后要求有两个指向，需要的对象被降为接近他者的手段（【张】§七 EPUB 文件53·P004、P009–P011）。

**判据的可操作形式是两个反事实：换掉给予者而保留同一对应物，不满是否重现；换掉对应物而保留同一给予关系，不满是否重
现。** 不满随给予关系变化的是要求；不满随对象更换而照旧、结构不变的，交给 3.3 判定。两书各提供一个校准：沈使用奥古斯
丁《忏悔录》的场景——过龄幼儿见到弟弟哺乳而吵闹，被剥夺的不是营养而是独占的给予关系，沈用来说明"无需求仍有要求"
（【永】§二 p.59–60）；张则把要求的对象钉在给予者一侧（文件53·P004、P009–P011，见上）。

3.2 与 3.3 的先后不可颠倒：**文本若给出"改变给予方式即可终止"的反事实，判定就停在要求，不得因"给到之后仍不满足"而升
入欲望**——欲望的分量来自对象的可换性，而不是不满持续的时长。两个反事实文本都未交代时，逐项记"未知"，此时允许仅凭
3.3 的替换史判定欲望，但两项测试的实际结果都要写进报告。

### 3.3 对象可换性测试：区分欲望与要求

若文本显示对象可以不断替换而追问的结构不变，且每一次"给到"都不能终止，那么这不是要求过强，而是欲望。沈给出的机制
说法是：Φ 只是能指，所以欲望＝无尽重复的要求（【永】§六 p.265）；大他者场所中没有能指代表主体，主体只能以"欠缺"被
代表，于是欲望是转喻主体作为欠缺、永无对应所指（【永】§三 p.94–95）；欲望始终是对另一个欲望的欲望，故有"离心性"
（ex-centricité，S-Ⅴ:329，【永】§二 p.85–86）。执行这一步时必须写下**被换掉的是什么、始终没变的是什么**；写不出这两
项，"欲望"就只是一个说法，不能进入结论。文本若未提供替换史，判为证据不足，层次停在 3.1–3.2 得出的结果，不得写欲望。

### 3.4 禁止用深浅替代测试

需要与要求的分离**不是**规模之别（护栏见 [`concept_reconstruction.md`](../../Validation/Lacan-Studies-Phase1/concept_reconstruction.md)
§四，基于【永】§二 p.57–67）。因此"他要求太多""他想要的程度很深"都不构成欲望的证据；同样，"他只是饿了"也不构成需
求的充分证据——如果文本讨论的恰恰是他如何表达这份饥饿，就仍需回到 3.2 的给予者测试。

### 3.5 禁止把结构读成发生史

凡结论句式形如"人在失去本真的需要之后才开始欲望"，须改写为结构关系陈述。可识别的句式标记有三类：把某一层放在时间上
的"之前／之后"（"失去……之后才开始""在人最初……"）、把结构落差说成事件的"一旦……便……"、以及用"曾经拥有／后来丧失"
描述需要状态的表述。出现任一类即触发改写，改写后的句子应当只谈三者之间的关系而不谈先后。沈为此设了一条明确限制：infans 进入语言
只能是一种结构的假设，无法在历史时间中溯源（【永】§三 p.88 注2）。张一兵的写法是反面教材式的：他把三分叙述为胎内→
出生→语言的序列，并自认这是"发生学的逻辑"（【张】§七），同一节却又引录需要"总是已经"与象征性媒介融为一体的说法（文
件53·P008）。【推】两句在同一节内互相抵消，所以张的发生学句式不可借用为阶段论证据；要作历史主张，须另有接受史或原典
依据（并转 `SOP-LAC-03` §3.6）。

### 3.6 归因回置：把读法留在原位

若 3.3 得出"欲望是他者的欲望"，两书提供的两种读法不得合并。沈拒绝把该命题读成黑格尔式的"受局限"（Beschränkung）
关系，强调二者不可比拟、没有共同基准（【永】§六 p.265–266）——这是对一句常被当作承认辩证法之用的标准读法的显式拒绝。
张则把它组织为"我欲他欲故我不在"的夺魂结构（【张】§七）。结论应当写成"该文本呈现的是要求／欲望层次；按沈的处理，此
处不引入承认辩证法；按张的处理，会读作他者之欲的接管"，而不是写成"拉康认为"。

## 4. 重要失败模式

层次降级：把不可满足解释为"还没得到够好的 X"，从而把欲望写成尚未满足的要求。层次升级：把明确指向某个给予者的不满
直接抬为欲望，跳过 3.2。以强度分层替代测试（3.4）。以文本没有的信息补足替换史，从而让 3.3 通过。把结构假设写成童年
事件（3.5）。把三层用于真实的人，或把判定说成对某人的诊断；同样地，把判定扩展到某个群体、某种文化的整体动机（例如据三层解释某一群
体的消费行为）也已越界（超出本 SOP 的许可，也超出这一阶段的全部材料）。跨书混用
术语而不在 2 中声明取哪一套：注意"需要／需求"在两书中并非稳定同义，沈译多用"需求"，张多用"需要"。

## 5. 输出与报告格式

四行固定格式，便于复核：

1. **判定层次**：需求／要求／欲望／证据不足。
2. **支持判定的文本特征**：三项测试各自的实际结果，未提供者逐项标"未知"。
3. **许可与禁止**：该判定允许写出的表述（例如"该文本呈现一个不能由对应物终止的要求"），以及禁止写出的表述（例
   如"它显示主体曾被剥夺本真的需要"）。
4. **读法差异与停止点**：两书在此层次上的处理差别，以及推断在哪一条证据处终止。
