## 目标与范围

在第一阶段已合并的两本研究著作笔记上，提炼**少量真正可用于文本与理论研究的 SOP，以及对应的可执行 BC**。本阶段是二手文献基础上的初步方法，不是拉康原典校勘、临床操作手册，也不宣称某个精神分析理论在经验上已被验证。

先前在本分支由助手生成的 2 SOP + 2 BC 草稿已撤下。**不要依据历史提交恢复它们，也不要照着其标题和提纲重写**；请 Codex 自行从第一阶段内容中选取有研究价值的具体任务。

## 执行

1. **挑选研究任务**。优先选择能由现有材料支撑、又能真正改变分析者判断的功能。例如：需要／要求／欲望的辨析；能指链、隐喻／转喻的不同作用；主体／自我、大他者／小他者或对象 a 的混淆识别；跨作者、跨历史阶段的解释冲突。以上是候选项，不是必须全部完成的清单。避免只产出“引用要有出处”这种一般文献管理 SOP。
2. **写 SOP**。从实际问题出发，交代为什么这些区分是必要的；给出输入、关键推理步骤、一个具体文本例子、可交付结论以及在哪些证据处应停止推断。用作者原有区分构建步骤，但不将争议解释写成普遍定律。篇幅以把论证和步骤讲清为准。
3. **写相配 BC**。每个 BC 必须对应某一项 SOP 所要避免的具体误读，准备至少一组正例／易混淆的对照例，说明期待看到的区分及失败条件。测试的是**文本分析质量**，不是临床疗效或某哲学流派“得分”。可以用中性、虚构的短文本作分析材料，但不能虚构原书原话或原书页码。
4. **做一次小规模实际试用**。各选一两个案例运行 SOP 和对应 BC，保留必要的输入、关键输出和观察到的问题；不通过时就修订相关文本。不得因为完成了文件就标为 PASS；不需要独立测试报告或评分仪表盘。
5. **收尾**。分别在 `SOP/Lacan-Studies-Preliminary/`、`Benchmark/Lacan-Studies-Preliminary/` 下写精简索引和正文，并在仓库根 `README.md` 中加一条草案链接。只修改本主题所需文件。提交并推送当前分支，保持 `main` 不变，不自行合并。

## 交付判断

建议起步为 **2–3 个具有不同研究功能的 SOP 及对应 BC**；若现有材料只支持更少，就少做并说明原因。每份必须可以回答“它比直接阅读概念摘要多提供了什么判断步骤”。优先质量，不为凑数扩充。

严禁使用 `exec`，不启动子代理。不要新建复杂规范、工作流引擎、知识图谱、量化评分器、重复校验脚本或大批模板；不进行无关的 AGENTS/README 全量重构。研究文本保持中文、术语可附原文，避免短句堆叠和机械格式。
