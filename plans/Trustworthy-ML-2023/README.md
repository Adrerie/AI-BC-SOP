# Trustworthy Machine Learning (2023) Plan Group

This plan group converts the methodological content of *Trustworthy Machine Learning* (2023) into reusable SOPs and Benchmarks for the AI-BC-SOP repository.

## Core Rule

Do **not** reproduce the book chapter-by-chapter.

The book is a source of concepts, methodological warnings, evaluation ideas, definitions, and procedures. The final repository artifacts must be reorganized according to our own research workflow and evaluation logic.

The local model must first inspect the complete table of contents and all available section/subsection headings. Relevant body text may be consulted whenever headings alone are insufficient to recover definitions, methodological details, metrics, assumptions, caveats, examples, or relationships between concepts.
